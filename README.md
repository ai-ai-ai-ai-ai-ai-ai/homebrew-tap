# Homebrew Tap

Homebrew formulae for tools published by ai-ai-ai-ai-ai-ai-ai.

Meta-Cortex releases generate `Formula/meta-cortex.rb` with cargo-dist.
The formula downloads prebuilt binaries from the Meta-Cortex GitHub releases.
Do not edit generated formulae manually.

## Publishing

The Meta-Cortex release workflow publishes formula updates here using its
`HOMEBREW_TAP_TOKEN` Actions secret. Grant that token Contents read/write access
to this repository.

This tap and the source repository are public. No formula has been published
yet. After the first release, install Meta-Cortex with:

```sh
brew install ai-ai-ai-ai-ai-ai-ai/tap/meta-cortex
```
